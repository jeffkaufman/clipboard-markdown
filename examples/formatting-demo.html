Dropped

Styling

Everything about how this page looks is dropped: the text and background colors, the font family, font sizes, letter spacing, shadows, and highlighting. The words stay; only the look goes.

This paragraph is centered, but will paste left-aligned.

This one is right-aligned, and will too.

Small text and big text become ordinary text, and so does HTML in an abbreviation.

Formatting done with CSS instead of tags

Formatting is kept when it uses real tags, like this bold, but not when the page fakes it with styles: this looks bold, this looks italic, and this looks underlined, but all three paste as plain text.

This looks like a heading, but is a styled paragraph, so it pastes as ordinary text.

Styles that change the text itself are lost too: this is written in lowercase and styled to look uppercase, and this is in small caps.

Layout

This rounded box is a div. The border, padding, and background go away, and the text becomes a normal paragraph.

Here is a badge in the middle of a sentence; it pastes as just the word.

Unsafe or unsupported content

A javascript: link keeps its text but loses the link, and so does a link to a local file.

An image embedded as a data URL is removed entirely: (there was a small red square before this).
